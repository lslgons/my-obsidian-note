# 작성지침 (51_AI노트)

AI(뚝딱)가 노트를 작성할 때 따르는 지침. 루트 AGENTS.md 규칙을 이 폴더에 적용한 것.

## 저장 위치
- AI가 작성하는 모든 문서는 이 폴더(`51_AI노트`)에 저장한다.
- 세부 위치는 사용자가 요청 시 지시하는 방향(주제/하위 폴더)에 따른다.

## 파일명
- `01_` 형식의 접두어로 정렬 순서를 유지한다. 숫자는 이 폴더 내에서만 유효하다.
- 새 주제 문서 생성 시 기존 번호를 확인하고 다음 번호를 배정한다.

## 이미지
- 모든 이미지는 `/images` 폴더에 보관한다.
- 파일명 충돌 방지를 위해 파일명 안에 저장 경로(주제명)를 포함한다. 예: `images/51_AI노트-주제명-설명.png`

## 목차
- 이 폴더의 목차는 `00_목차` 파일로 관리하며, 새 문서 추가 시 갱신한다.

## 작성일/수정일
- 모든 노트는 YAML frontmatter에 작성일과 수정일을 기록한다:
  ```yaml
  ---
  created: 2026-11-22
  modified: 2026-11-22
  ---
  ```
- 노트를 수정할 때마다 `modified`를 그날 날짜로 갱신한다.

## 노트 작성 흐름
1. 사용자의 요청 지시(주제, 방향성)를 확인한다.
2. `01_` 번호 배정 → 마크다운 작성, 필요 시 `[[위키링크]]`로 관련 노트 연결.
3. `00_목차`에 항목 추가.
4. 반드시 커밋 후 푸시한다 (author: lslgons <lslgons@naver.com>).
