# 개발환경

[https://quasar.dev/start/quick-start](https://quasar.dev/start/quick-start)

node.js설치 : [https://nodejs.org/dist/v18.17.1/node-v18.17.1-x64.msi](https://nodejs.org/dist/v18.17.1/node-v18.17.1-x64.msi)

워크스페이스 초기화

```bash
# Quasar CLI설치
npm install -g @quasar/cli
#워크스페이스 설정 (옵션 많음)
npm init quasar
# 개발서버 실행
quasar dev
```
