# 타입과 연산

스칼라(Scala)에서는 다양한 타입과 연산을 지원합니다. 스칼라는 정적 타입 언어로서, 변수와 표현식의 타입을 컴파일 시점에 검사합니다. 이를 통해 안정성과 가독성을 높일 수 있습니다.

스칼라에서는 기본적인 데이터 타입인 정수형(Int), 부동 소수점형(Double), 문자열(String) 등을 제공합니다. 또한, 컬렉션 타입인 리스트(List), 배열(Array), 맵(Map) 등을 활용하여 데이터를 구조화하고 처리할 수 있습니다.

타입에 따라 다양한 연산을 수행할 수도 있습니다. 예를 들어, 정수형 데이터끼리의 사칙 연산이나 논리 연산, 문자열의 결합 등이 가능합니다. 또한, 스칼라는 함수형 프로그래밍 언어의 특징을 갖고 있기 때문에, 고차 함수와 람다 식을 활용한 함수형 연산도 가능합니다.

### 리터럴

정수 리터럴은 정수 타입(Integer Type)인 Byte, Short, Long, Int, Char 중 Char를 제외한 모든 정수 타입에 적용된다. 정수 리터럴은 `10진 리터럴`과 `16진 리터럴`이 존재한다.

수가 `0x`나 `0X`로 시작하면 16진수이다.

**정수를 초기화하기 위해 리터럴에 사용한 진법과 관계없이 스칼라는 항상 밑을 10으로 하는 정수를 출력해준다**는 점

부동소수점 리터럴은 십진 숫자들로 이루어진다. 소수점이 있을 수 있으며, 마지막에 `E`나 `e` 다음에 지수 부분이 있을 수 있다.

문자 리터럴은 작은 따옴표 안에 유니코드 문자를 넣어서 만든다.

자를 **유니코드 코드 포인트(unicode code point)**를 사용해 지정할 수 있다. 그렇게 하려면 위의 예시처럼 **`\u`** 다음에 4자리 16진수를 넣으면 된다.

심볼 리터럴 : 스트링과 유사하나 단 하나의 객체만 존재, " 'string "형태로 작성되나 더이상 지원안함 (Symbol("string")형식으로 작성하여야 함)

```scala
val hex=0x00FF // 255
val big=1.2345
val biggerStill=123E45 // 1.23E47
val tower=35L
val d='\u0041' // A
```

### 문자열 인터폴레이션

- s : 인터폴레이터를 내장된 각 표현식을 평가하고 toString의 결과로 대치
- raw : 문자열 이스케이프 시퀀스를 인직하지 못함
- f : printf 스타일 형식을 지정

```scala
val name="some_name"
println(s"Hello $name")

println("No\\\\escape sequence!")
println(raw"No\\\\escape sequence!")

val value:Double = 1.23456
println(f"$value%.2f")
```

### 객체 동일성

두 객체가 같은지 비교하고 싶다면 `==`를 사용하며, 같지 않은지를 비교하려면 `!=`를 사용한다

스칼라도 참조 동일성을 검사하는 기능이 존재하지만, `eq`가 그 기능을 담당한다.
