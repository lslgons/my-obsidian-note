# HA Proxy - 고가용성 클러스터

마스터 노드 장애 시 워커노드 영향도를 제거하며 부하를 분산시키기 위한 목적

- 마스터노드 3개를 클러스터로 구성
- 가상 네트워크 (weave)적용
- ceph storage 적용
