# Spring boot

API와 메시지 기반의 비동기 서비스 (리액티브 마이크로서비스)

논블로킹 동기 REST API는 스프링 웹플러스를 사용하여 개발하게 됨

메시지 기반의 비동기 서비스는 스프링 클라우드 스트림 (Kafka 대체가 될 수 있을 것 같음)

리액티브 프로그래밍 : [리액티브 프로그래밍에 대하여 (velog.io)](https://velog.io/@korea3611/%EB%A6%AC%EC%95%A1%ED%8B%B0%EB%B8%8C-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D%EC%97%90-%EB%8C%80%ED%95%98%EC%97%AC)
