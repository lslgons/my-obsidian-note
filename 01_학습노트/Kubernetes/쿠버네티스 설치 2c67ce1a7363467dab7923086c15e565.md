## 1.2 도커 및 kubeadm 설치

도커 설치 명령어

```yaml
sudo apt update
sudo apt install docker.io -y
```

다음 스크립트 파일을 작성하고 스크립트를 실행한다.

```bash
gedit kube_install.sh
sudo sh kube_install.sh
```

```bash
# kube_install.sh
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl
sudo curl -fsSLo /usr/share/keyrings/kubernetes-archive-keyring.gpg https://packages.cloud.google.com/apt/doc/apt-key.gpg
echo "deb [signed-by=/usr/share/keyrings/kubernetes-archive-keyring.gpg] https://apt.kubernetes.io/ kubernetes-xenial main" | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo apt-get update
sudo apt-get install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
```

설치가 완료된 후 다음 명령을 입력하고 TAB 키를 누른다.

```bash
# kube<TAB>
kubeadm  kubectl  kubelet
```

추가로 필요한 애플리케이션 설치

```bash
sudo apt install vim net-tools -y
```

# 3 클러스터 구성 및 쿠버네티스 테스트

## 3.1 스왑 기능 비활성화하기

```bash
sudo swapoff -a
sudo sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab
```

## 3.2 도커 cgroups 변경하기

도커 기본 cgroup인 cgroupfs에서 systemd로 변경 필요

1. 현재 도커의 cgroup 확인
    
    ```yaml
    $ sudo docker info | grep -i cgroup
    WARNING: No swap limit support
     Cgroup Driver: cgroupfs
     Cgroup Version: 1
    ```
    
2. 도커 데몬의 설정파일 구성
    
    ```yaml
    cat <<EOF | sudo tee /etc/docker/daemon.json
    {
      "exec-opts": ["native.cgroupdriver=systemd"]
    }
    EOF
    ```
    
3. 도커 재시작
    
    ```yaml
    service docker restart
    ```

# 5 쿠버네티스에서 실행할 Go 언어 컨테이너 작성

[main.go](%EC%BF%A0%EB%B2%84%EB%84%A4%ED%8B%B0%EC%8A%A4%20%EC%84%A4%EC%B9%98/main%20go%20c9a6e903d4e64883ab8b1a863070f51d.md)

main.go

```bash
package main

import (
    "fmt"
    "github.com/julienschmidt/httprouter"
    "net/http"
    "log"
    "os"
)

func Index(w http.ResponseWriter, r *http.Request, _ httprouter.Params) {
    hostname, err := os.Hostname()
    if err == nil {
        fmt.Fprint(w, "Welcome! " + hostname +"\n")
    } else {
        fmt.Fprint(w, "Welcome! ERROR\n")
    }
}

func main() {
    router := httprouter.New()
    router.GET("/", Index)

    log.Fatal(http.ListenAndServe(":8080", router))
}
```

고 설치 및 앱 작성 후 실행

```yaml
$ apt install golang
$ go get github.com/julienschmidt/httprouter
$ go build main.go
$ main
$ curl 127.0.0.1:8080
```

dockerfile

```yaml
FROM golang:1.11
WORKDIR /usr/src/app
COPY main  /usr/src/app
CMD ["/usr/src/app/main"]
```

도커 빌드 및 푸시

```bash
$ sudo docker build -t gasbugs/http-go .
$ sudo docker login
$ sudo docker push gasbugs/http-go
$ sudo docker run -d -p 8080:8080 --rm http-go
$ curl 127.0.0.1:8080
```

# 7 쿠버네티스를 활용해서 Jenkins 서비스하기

모든 자원 삭제

```yaml
kubectl delete all --all
```

hub.docker.com에서 젠킨스에 대한 정보 확인

[https://hub.docker.com/r/jenkins/jenkins](https://hub.docker.com/r/jenkins/jenkins)

```yaml
jenkins/jenkins:lts-jdk11
```

```yaml

kubectl expose deploy jk --type=LoadBalancer --port=80 --target-port=8080
```
